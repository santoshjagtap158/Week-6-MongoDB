# Week 6 – Day 1: Introduction to Databases & MongoDB

 Project Overview

This project demonstrates basic database operations using MongoDB Atlas and MongoDB Compass.

 Database Details

* **Database Name:** University_Programs
* **Collection Name:** programs

 Operations Performed

* Created a database and collection.
* Inserted university program documents.
* Retrieved documents using queries.
* Filtered programs by department using `Department`.
* Updated the MCA program fee from 65000 to 67000.
* Deleted the DCA program document.

 Tools Used

* MongoDB Atlas
* MongoDB Compass

Screenshots

Screenshots demonstrating database creation, department filtering, and the updated MCA fee are available in the `screenshots` folder.

 Learning Outcome

Learned how to create a MongoDB database and collection and perform basic CRUD operations.
